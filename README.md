## Project Name: 
Fit Log
## Project Des:
Fit Log is a simple workout management website. Users can explore workouts, create a daily workout plan, and save their favorite workouts.

## Technologies Used
Next.js
React
TypeScript
Tailwind CSS
DaisyUI
React Toastify
Lucide React Icons
## Key Features
1.Users can browse different workouts.
2.Users can add workouts to Today's Plan.
3.Users can save their favorite workouts.
4.Users can remove workouts from their plan.
5.Users can see their workout plan in an organized way.
